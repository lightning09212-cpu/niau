# 美容師求人リールメーカー

美容師求人用のInstagramリール台本、テロップ、CapCut編集指示、キャプション、CTA、ハッシュタグを生成するローカル対応Webアプリです。

## 使い方

1. `index.html` をブラウザで開く
2. 求人情報を入力する
3. 「生成する」を押す
4. 必要な出力をコピーしてInstagramやCapCutで使う

## ファイル

- `index.html`: 画面構成
- `styles.css`: デザイン
- `script.js`: 文章生成ロジック
- `standalone.html`: CSSとJavaScriptを内包した1ファイル版。AirDrop後にiPhoneで開く用途向け
- `standalone-copy-paste.txt`: GitHubの `index.html` 編集画面に貼り付けるためのコピペ専用ファイル
- `COPY-PASTE-GUIDE.md`: GitHubへコピペする時の超簡単ガイド

ログイン機能やサーバーは不要です。

## コピペで使いたい時

**`standalone-copy-paste.txt` を開いて全部コピーし、GitHub上の `index.html` に貼る**のが一番簡単です。
